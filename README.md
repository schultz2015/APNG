# APNG 涩涩合成工具

一个基于浏览器的 APNG 动画合成与拆帧工具，用来 QQ 发图。

在线使用：[https://schultz2015.github.io/APNG/](https://schultz2015.github.io/APNG/)

## 功能

- 上传、拖拽或粘贴图片，调整图片帧顺序
- 设置帧延迟、输出尺寸和图片适配方式
- 支持全局模糊、圆球马赛克、毛玻璃蒙版、像素画艺术和半色调网点
- 滤镜强度、颜色量化、色带质量和降采样倍率
- 半色调网点提供 Material 风格浮窗，可实时设置最多 3 个独立油墨色版、纸张预设和全局网点对齐模式（点对点叠印、错位对齐、玫瑰斑）
- 在线预览并下载 APNG
- 将 PNG 或 APNG 拆解为独立 PNG 帧

半色调色版由 `apply_channel_alignment` 根据通道数、基础角度、网点频率和对齐模式动态生成角度与网格偏移，支持 2 或 3 个通道。所有布局模式都会对非基准通道叠加独立的随机套色偏差，强度为网点周期的 4%；同一通道在预览和输出过程中保持该偏差稳定。错位模式的频率使用每像素网点周期数（`freq = 1 / 网点间距像素`），因此偏移与图像像素尺寸一致。

未开启滤镜预览时，合成至少需要两张图片；只添加一张时，合成按钮会提示开启滤镜预览或添加更多图片。开启滤镜预览后，滤镜图作为 APNG 默认预览，上传的原图作为动画帧，不会额外复制动画帧。

滤镜预览 PNG 按当前输出尺寸生成，而非使用界面缩略图。为控制动画插画的输出体积，非 PNG 来源帧（包括滤镜预览）会自动量化到最多 256 色后再封装；非 PNG 帧共用调色板并以索引色存储。PNG 来源帧不会额外量化，保持像素无损。JPEG、WebP、GIF 等输入转成 PNG/APNG 时，量化可能带来轻微色差，但可显著降低大尺寸帧的体积。

## 本地运行

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。

## 构建

```bash
npm run build
```

构建产物位于 `dist/` 目录。
